# Project brief

Fill this in BEFORE building. The AI agent will read it.
Be specific — the factory builds exactly what you write here.

## What is this project?
One sentence. Example: "A portfolio site for a fashion photographer."

## Who is it for?
Who visits it, and what are they trying to do?

## Pages / sections
List them. Example: home, portfolio gallery, about, contact.

## Key content
Copy, images, links, prices. Anything real you already have.

## Design direction
Style words, reference sites, colors, fonts. Empty = agent chooses clean defaults.

## Must work
- [ ] Mobile
- [ ] Desktop
- [ ] Keyboard accessible

## Out of scope (important - protects you from scope creep)
What this project is explicitly NOT doing.
